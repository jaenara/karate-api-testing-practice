# Karate API Testing Practice

Proyecto de automatización de pruebas API utilizando Karate Framework, Maven y Java.

## Tecnologías utilizadas

- Java 21
- Maven
- Karate Framework
- JUnit 5

## Escenarios implementados

### Users API
- Validación de status code
- Verificación de datos JSON
- Validación de estructura de respuesta

### Posts API
- Validación de endpoint GET
- Verificación de datos de respuesta

### Create User API
- Test de creación de usuario
- Validación de respuesta POST
- Verificación de datos enviados

## Cómo ejecutar los tests

```bash
mvn test
```

## Objetivo

Este proyecto fue creado como práctica de automatización QA orientada a testing de APIs REST utilizando Karate Framework.
